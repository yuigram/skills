# Навыки для Yuigram

[English](README.md) · Русский

Навыки (skills) для агентов, которые пишут, проверяют или отлаживают код на
[Yuigram](https://github.com/yuigram/yuigram) — TypeScript-фреймворке для Telegram Bot API и
MTProto. Каждый навык — каталог с файлом `SKILL.md`: короткое описание, по которому агент решает,
когда его загрузить, инструкции и справочные файлы, которые открываются только при необходимости.

## Навыки

| Навык | Для чего |
| --- | --- |
| [using-yuigram](using-yuigram) | Точка входа: выбор клиента и точки импорта, правила импорта и безопасности, уровни доказательности. Содержит инструменты проверки версии и поиска экспортов. |
| [yuigram-bot](yuigram-bot) | Боты на Bot API: создание, polling и вебхуки, контексты, фильтры, роутеры, клавиатуры, файлы, лимиты и повторы. |
| [yuigram-account](yuigram-account) | Аккаунты на MTProto: настройка, вход, строки сессий, владение хранилищем, события, собеседники, отправка, списки, файлы, параметры вызовов. |
| [yuigram-state](yuigram-state) | Сессии, хранилища, SQLite и Redis, диалоги и устойчивые сценарии, callback data. |
| [yuigram-formatting](yuigram-formatting) | `html` с `parse_mode`, форматированные значения из `yuigram/markup`, богатые сообщения, форматирование для аккаунта. |
| [yuigram-testing](yuigram-testing) | `mockBot`, `mockAccount`, заготовки и то, как описывать, что показывает тест. |
| [yuigram-stream](yuigram-stream) | Ответ черновиком по мере написания — у бота и у аккаунта. |
| [yuigram-worker](yuigram-worker) | Аккаунт в воркере, управляемый из другого потока. |

## Совместимость

Навыки проверены на исходном коде Yuigram ревизии `cda2040165570735886b7d73efe06ee80a1f9920`
(Bot API 10.3, слой TL 232), выпущенной как версия `1.1.0`. `Account`, `App` и `bootstrapAt`
появились в `1.0.0`; `0.1.0` был только клиентом Bot API. Строка версии не указывает на ревизию
исходного кода, поэтому установка проверяется по тому, что пакет сообщает о себе и экспортирует,
а не по версии:

```bash
node <skills-dir>/using-yuigram/tools/check-version.mjs
```

Запускайте из проекта, где установлен `yuigram` (или передайте `--from <каталог-проекта>`).
Инструмент выводит по отдельности четыре вещи: проверенную ревизию исходного кода, установленную
версию, обнаружены ли необходимые возможности и происхождение пакета. Код выхода `0` — необходимые
возможности обнаружены, `1` — не обнаружены (навыки описывают другую поверхность), `2` — `yuigram`
не установлен. Код `0` не доказывает, что установлен именно проверенный вариант: упакованные и
опубликованные пакеты сейчас не записывают ревизию исходного кода, поэтому происхождение
сообщается как неизвестное, если в манифесте пакета нет поля `gitHead`. `list-exports.mjs` перечисляет экспорты точки входа
или находит, откуда экспортируется имя. Обоим инструментам нужен Node.js 22; они только читают
установленный пакет и не обращаются к сети.

## Установка

Агенты загружают навыки из каталога навыков; какого именно — зависит от агента, см. его
документацию. Склонируйте этот репозиторий:

```bash
git clone https://github.com/yuigram/skills yuigram-skills
```

Затем скопируйте или подключите ссылками каталоги навыков в каталог навыков:

```bash
cp -R /path/to/yuigram-skills/using-yuigram /path/to/yuigram-skills/yuigram-* <skills-dir>/
```

Ссылки сохраняют навыки в соответствии с клоном:

```bash
for skill in /path/to/yuigram-skills/using-yuigram /path/to/yuigram-skills/yuigram-*; do ln -s "$skill" <skills-dir>/; done
```

В Windows то же самое делает `Copy-Item -Recurse` в PowerShell. Устанавливайте навыки вместе:
узкие навыки ссылаются на `using-yuigram` за правилами импорта и безопасности.

## Чему навыки учат агента

- Импортировать только из `yuigram`, его объявленных подпутей, `@yuigram/sqlite` и
  `@yuigram/redis` — никогда из внутренних пакетов и файлов.
- Не выводить токены, API hash, строки сессий, коды входа и пароли — ни в ответах, ни в логах,
  ни в коммитах, ни в переписке; программы читают их из окружения.
- Не подключаться к Telegram, не входить в аккаунт и не отправлять сообщения, пока пользователь
  не попросит именно такой запуск; проверять через поддельные клиенты.
- Сообщать о проверке на том уровне, который действительно достигнут: типы, запуск на
  моках, запуск в среде выполнения, запуск на Telegram — и никогда не сообщать о проверке, которой
  не было. Не заглушать ошибку, чтобы она «прошла».

## Язык

Инструкции написаны на английском: это язык идентификаторов, документации и сообщений об ошибках
Yuigram и обычная практика для наборов навыков, так что агент видит один словарь и в навыке, и в
коде. Агенты пользуются ими на каком угодно языке разговора. Это введение есть
[на английском](README.md).

## Сопровождение

Когда Yuigram меняется, обновите `tested_revision` (а также `tested_package_version`, `bot_api`,
`tl_layer`, `requires`) во всех `SKILL.md`, где они есть, и проверьте репозиторий:

```bash
node scripts/validate.mjs
node scripts/extract-examples.mjs <проект-с-yuigram>/skill-examples
```

`validate.mjs` проверяет структуру: имена, описания, общую ревизию, разрешённые инструменты,
ссылки. `extract-examples.mjs` записывает каждый пример на TypeScript в отдельный модуль;
скомпилируйте их `tsc --noEmit` в проекте с установленным `yuigram`, объявив имена, которые
предполагают фрагменты, как описано в заголовке скрипта. Пример, который перестал
компилироваться, — признак устаревшего навыка.
